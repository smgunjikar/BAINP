# BAINP roadmap — build order and future scope

## Hackathon core, 2026

**Checkpoint 0 (today)**: existing GitHub cloned, files in place, first commit pushed, backend test workflow green.

**Checkpoint 1**: working local API + frontend, demo-only patient and clinician views, synthetic baseline/test sessions, clear privacy warning.

**Checkpoint 2**: ADNI/OASIS metadata inventory and cohort quality audits; no licensed files in Git; versioned research analysis notebooks.

**Checkpoint 3**: NeuroVision structural research, NeuroCognition repeated tasks, NeuroGuard quality/abstention, clinician-facing summaries, CareLoop follow-up.

**Checkpoint 4**: PADS wearable baseline; OpenNeuro EEG signal processing with recording replay explicitly identified; separated cohort benchmarks.

**Checkpoint 5**: demonstration, tests, independent caveats, accessibility, reproducibility, pitch and deployment using **synthetic data only**.

## Longer-term 2027+

- Validation of linguistic/cultural accessibility and person-specific repeated measurements.
- Research-grade NeuroTwin with larger longitudinal cohorts, uncertainty and independent validation.
- NeuroPulse via qualified EEG or ear-EEG hardware; peripheral wearable/ECG/PPG streams; physiological synchronization.
- NeuroGraph evidence provenance, NeuroSim guideline-linked prevention, Brain–Body Signal Atlas.
- Retina/OCT, fNIRS, speech, sleep, genomic and clinically obtained blood biomarker research under appropriate governance.
- Prospective clinical studies and regulatory evaluation before any patient-specific diagnostic/triage claims.
- Future B2B clinics/research programmes and population-level systems, subject to privacy, legal and clinical approvals.

The names NeuroVision, NeuroPulse, NeuroTwin, NeuroGuard, NeuroGraph, NeuroSim and CareLoop describe project workstreams, **not** medically validated products.
