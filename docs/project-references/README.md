# BAINP project references

These are the user's supplied design proposals, preserved as source material. They describe intended capabilities, not proof of implemented or clinically validated features. Verify external claims, dataset access and hackathon rules before relying on them. Dates and status statements are historical.

- `01-master-architecture-proposal.txt`: platform vision, modules, datasets, proposed stack and workflows.
- `02-bainp-3-design-proposal.txt`: NeuroTwin, assessment concepts and reliability proposals.
- `PROJECT_STRUCTURE.md`: a practical incremental repository map and current implementation status.

Research datasets remain separate. Do not add raw data, private participant information, credentials or model artifacts to this folder.
